# openRepoTools v1.0.0

This tag marks the baseline for versioned releases: openRepoTools as it stands on `main` at `aaa7bc8`, on 2026-10-17.

openRepoTools holds three things:
- **The estate commands.** `park <Name>`, `resume <Name>` and `status <Name>` work on the estates that [openRepoShape](https://github.com/opensoft/openRepoShape) scaffolds.
- **The lane tooling.** `lanes-edit.sh`, `lane-start`, `lane-end`, `link-estates` and their helpers record the work, under the lane collision protocol. `docs/README-lanes.md` is their manual.
- **The installer.** `openRepoTools --install` places the tools, and `openRepoTools wip init` creates the workspace they read.

This release pins openRepoShape at `7f84ca4`, the commit its tests were verified against.

**Not on PyPI.** The first PyPI release will be **v1.1.0**. It will be published from the code leg after the triad migration (#186), through a tag-gated release workflow with TestPyPI first, modelled on openRepoShape's. Until then, `openRepoTools --version` still prints the repository and ref it was installed from.
