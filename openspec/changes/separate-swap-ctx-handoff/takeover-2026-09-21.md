## Native ctx evidence blocker found during implementation

Astra's execution review established that the publication/adoption contract
does not define a ctx-specific authoritative worker-state-clear observation
before source shutdown. The swap observer's `graph-drained` proof depends on
its prior entry epoch, swap metadata, target pin, and stage ledger. A ctx
operation cannot impersonate that swap or reuse an earlier proof. The adoption
provider binds an archive and asserts source exclusion, so it cannot truthfully
supply the earlier pre-shutdown gate. Terminal children or process exit alone
are not evidence of runtime worker-state clearing.

A proposed next design step is an explicitly ctx-bound entry-to-graph-drained
evidence prefix with immutable request epoch, actual target-spec digest,
independent runtime pin, source/interrupt joins, durable negative evidence,
and an authoritative emitter. This is **not an approved contract adaptation**
or evidence that the selected runtime can produce it.
